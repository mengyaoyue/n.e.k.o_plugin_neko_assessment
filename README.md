# 心理测评室（neko_assessment）

心理测评 · 人格测评 · 趣味测评，一个面板全包。**一题一屏**、答题时**实时看维度剖面**、
结果可**追踪趋势**、可**复制 / 导出 / 生成分享卡**。
答案与结果**只写在本机 `data/records.json`**，不上传、不联网。

> ⚠️ 全部量表**仅供自我了解与反思，不是医学诊断**，也不能替代心理咨询或治疗。

## 二、怎么用

1. 在插件管理里 **打开界面**（或在对话框发 `/测评` 看清单）；
2. 选一份量表 → 一题一屏作答（**键盘 1-5 直接选，Enter 下一题，Backspace 回上一题**）；
3. 答题时下方会**实时显示维度剖面**（随你的选择变化）；
4. 结果页：类型卡 + **雷达图** + 维度条 + 长处/盲点；可**复制结果**、**生成分享卡（PNG）**、**再测一次**；
5. 「记录」页看历史与**趋势**，支持按量表筛选、导出文本、单条删除、一键清空。

PHQ-9 第 9 题（自我伤害念头）若有得分，结果页会**优先显示危机求助热线**——请务必先看那一块。

## 三、隐私

- 数据文件：`data/records.json`（记录）、`data/panel_prefs.json`（界面偏好）、`data/backgrounds/`（可选背景图）。
- 不联网、不上传、不给第三方；可随时导出或清空。
- 打包发布时 `data/` 被排除，**不会混进发行包**。

## 四、目录结构

```
neko_assessment/
├── __init__.py       插件主体：面板服务、接口、聊天入口
├── _scales.py        题库（条目、维度、类型画像、来源声明）
├── _engine.py        评分引擎（反向计分、维度百分比、类型判定、分级）
├── _store.py         本机记录存储
├── _panel.py         面板服务（通用模板，零第三方依赖）
├── static/           面板页面 + 自托管字体 + 背景图
├── i18n/             8 语言
└── tests/            回归测试
```

## 五、接口一览

```
GET  /api/scales            量表清单（含已做次数）
POST /api/scale             取某份量表的题目
POST /api/submit            提交答案 → 计分 + 存记录
GET|POST /api/records       记录列表（可按量表筛选）
POST /api/records/delete    删除一条
POST /api/records/clear     清空全部
POST /api/history           某量表的历次得分（趋势）
GET|POST /api/prefs         界面偏好
POST /api/export            导出全部记录（文本）
```

## 六、开发

```bash
py -m pytest tests -q        # 回归测试（含评分正确性与面板契约）
```

新增量表只需往 `_scales.py` 的 `SCALES` 里加一条：**Likert 型**给 `options` + 条目 `dim/reverse`；
**选择型**给每项的 `options`（带 `weights`）。计分与面板会自动支持。
